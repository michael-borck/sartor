Project & provider

Your project stays in a plain folder you own. Provider settings are saved in that project's config; the API key itself stays in your OS keychain.

Project

If the folder is not yet a Sartor project, Save & start will initialize it.

Provider

Local Ollama and other local OpenAI-compatible servers usually need no key. No key value is written to the project.

Privacy: no account and no telemetry. Sartor runs locally; the only model traffic goes to the provider you configure.
